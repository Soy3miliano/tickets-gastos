Las fotos se suben a una carpeta llamada TicketsGastos en tu Drive. Necesitas un Client ID de Google (una sola vez).
¿Cómo consigo mi Client ID? (10 min, una sola vez)
  1. Entra a console.cloud.google.com y crea un proyecto nuevo (cualquier nombre).
  2. Ve a APIs y servicios → Biblioteca, busca Google Drive API y actívala.
  3. Ve a APIs y servicios → Pantalla de consentimiento OAuth. Elige "Externo", llena nombre y correo. En "Usuarios de prueba" agrega tu propio correo de Gmail.
  4. Ve a APIs y servicios → Credenciales → Crear credenciales → ID de cliente de OAuth. Tipo de aplicación: Aplicación web.
  5. En "Orígenes de JavaScript autorizados" agrega el origen desde el que abras este archivo (si lo abres con doble clic, agrega http://localhost y mejor ábrelo sirviéndolo localmente; lo más simple es subirlo a algo como GitHub Pages o abrirlo con la extensión "Web Server for Chrome").
  6. Copia el Client ID (termina en .apps.googleusercontent.com) y pégalo abajo.
